# Vonage → Tough Tongue NCCO webhook

Static NCCO (Nexmo Call Control Object) served as the Answer URL for the
Vonage Voice application "Tough Tongue Voice", bound to +44 20 3962 2786.

It tells Vonage to bridge the inbound call to Tough Tongue AI's SIP
endpoint for the "Mystery Patient (Blind Consult)" scenario.

Answer URL (raw): use the raw.githubusercontent.com link for answer.json
in this folder, on the main branch.
